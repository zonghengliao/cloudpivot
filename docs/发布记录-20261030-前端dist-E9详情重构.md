## 4. 两次红与本轮无关（已定位，另立卡跟踪）

1. **05 一次红 → 生产全局限流 429**：`backend/config/config-prod.toml` 里 `[middleware.rate_limit] requests_per_window = 300 / window_secs = 60`。
   连续跑多轮全量 e2e（每轮 200+ 请求）会把 60 秒配额打满，`GET /api/business/flow/task/todo` 直接 `429` → 待办列表空 → 用例 20s 超时。
   journal 佐证：`12:25:34 GET /api/business/flow/task/todo -> 429`。冷却后单跑即绿（第 3.2 节那条）。
   **结论：跑 e2e 别连着刷，一轮之间留 ≥1 分钟。**
