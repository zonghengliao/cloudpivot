## 6. 复核清单（下次谁再看见这条 BLOCKER 就这么查）

1. `di.c_di18` 里这两行的 `severity` 是不是 INFO —— 是，则已收口；变 ERROR 只有两种可能：豁免过期（`> 2027-02-04`）或有人删了 `di.v_poly_ref_waiver` 那一行。
2. `biz_inventory` 该物料该仓是否仍是 `qty=0 / amount=0 / avg_cost=0`（§2.3）。
3. 该物料流水是否仍只有 2 条、`ΣIN−ΣOUT=0`（§2.2）。
4. 序列号是否仍全部软删（`alive_total=0`，§2.1）——**不要恢复**：恢复等于把已冲销的库存件凭空造回来。
