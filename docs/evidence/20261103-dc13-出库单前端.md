## 4. 口径与决策

1. **按钮只由 `next_statuses` 驱动**：详情抽屉不写第二份状态机（单测断言「只喂两个目标 → 只出两个按钮」）。后端收紧 `DRAFT → POSTED` 直过时，页面自动跟着变。
2. **作废原因必填且对草稿也生效**（与 `ck_biz_so_cancel` 的 NOT NULL 同口径）：空理由连请求都不发。
3. **报废 / 盘亏事由必填**在前端先拦一道（后端 400 是第二道）；提示写明「要挂 1901 待处理财产损溢」。
4. **明细不带单价 / 金额 / 单位**：类型上就没有这些字段，单测显式断言 `unit_cost / amount / unit_id / price` 不在请求体里。
5. **不出参一律 null 化**：`reason` / `remark` 空串 → `null`，不留 `""` 让后端猜。
6. **一物一码物料在物料下拉里就被过滤掉**（后端 400 指路序列号管理），表单校验再兜一道。
7. **金额列口径**：列表列标题 `成本金额(过账后)`，草稿 / 待过账显示「过账后才有值」（不用 `0.00` 冒充真金额）；详情明细 `unit_cost` / `amount` 为 0 时显示「—」。
8. **状态历史**由 `created_at / posted_at / cancelled_at / cancel_reason` 拼出，只为真实发生过的里程碑打点（后端没有单独的历史接口，不编时间）。

## 5. 边界 / 遗留

- `PENDING_POST → 过账` 的「制单与过账分权」只在后端 `erp.separation_of_duties.post` 生效；前端不另做同人拦截（不做静默降级，报文由后端给）。
- 本卡未接出库审批流（DC-13 决策：本模块不声明流程，`PENDING_POST` 就是交接位）；若以后要接，需种 `stock_out_post` 流程 + bridge 回调，前端只需重画 `next_statuses` 的按钮，无需改逻辑层。
- 隔离库 `cp_so_fe` 与 18108 / 5231 两个进程在验收后已停（见完成说明）。
