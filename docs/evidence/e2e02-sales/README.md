## 勾稽验证（`99_reconcile.txt` 原始输出，8/8 通过）

1. **订单主表 = Σ明细**：三张订单 `total_amount/total_tax/total_with_tax` 与明细逐项相等，不一致行 0。
2. **应收恒等式**：`AR-…017 1356.0000 = 800.0000 + 556.0000`；`AR-…018 226.0000 = 0 + 226.0000`，违反行 0。
3. **应收 = 订单价税合计 + 退货红字**：`1582 + (−226) = 1356`；美元单 `226 + 0 = 226`，不一致行 0。
4. **发票**：4 张发票 `amount + tax = total` 全部成立；有效开票额（782）≤ 应收额（1356）。
5. **库存 = 流水累计**（本仓逐物料）：差异行 0；期末 M1=172（200−10+2−20）、M2=195。
6. **凭证借贷平衡**：本卡 10 张凭证逐张 `Σ借 = Σ贷`，不平张数 0。
7. **科目净额（本位币）**：`1122 净 1383.20`、`1405 净 1460.00`（1600−140）、`6401 净 140.00`、
   `2221.02 净 −251.16`、`5601 净 96.00`、`2241.02 净 0.00`（计提=发放）。
8. **1122 口径**：`782 纸质票 + 1627.20 美元票 − 1000 收款 + 200 退款 − 226 退货红字 = 1383.20`（实测一致）。
   `1122 ≠ Σ应收未收(2160.60)` 是**设计口径**：开票才确认收入（出库只挂应收不记 1122），
   差额 777.40 = 未开票 556.00 + 美元票汇兑 22.60 + 已收款对应未开票部分。
9. **销售目标**：订单口径 DB 本位币合计 3186.60 = 接口 3186.60；收款口径 800.00 = 接口 800.00。
10. **佣金**：基数 800.00（= 应收已收净额），佣金 96.00（= 800×12%，销售员规则压过全局 5%），
    明细按订单行金额分摊（228.5714 + 571.4286 = 800），关联 `SO-20261109-000020`。
