补充观察（6 个表单一致的行为）：
1. 编码输入框 placeholder 统一是「留空自动生成，如 <PREFIX>-<示例>」，辅助文案统一是
   「不点「生成编码」则保存时自动生成；生成后仍可手改（已有编码体系可直接填）」。
2. **预览不占号**在 UI 层同样成立：供应商点「生成编码」拿到 SUP-0019 后取消，重新建单不点生成，
   保存拿到仍是 SUP-0019；客户 CUS-0006、物料 MAT-0006、仓库 WH-06、资产分类 AC-06、费用类型 ET-06 同理。
3. 编辑态六个表单的「生成编码」按钮都**保留在 DOM 里但 disabled**（不是 v-if 隐藏），编码框 disabled，
   提示文案按实体分别说「编码是<实体>身份，不支持修改」。参数开关关闭时按钮才 v-if 隐藏（CODE-08 行为）。
4. 前端没有任何「编码必填」校验挡路：不点生成的建单全部一次通过（CODE-05/06 删掉的校验仍在生效）。

抓取方式：注入式 JS 点击（`document.querySelectorAll('button')` 按文本匹配）＋ `getBoundingClientRect().width>0` 过滤可见元素；
读值用 `.t-form__item input.value` / `.t-dialog input.value`，只读态读 `input.disabled`。
