## 2) 为什么必须按路径 add（共享工作区的硬约束）

`/opt/cloudpivot` 是**多个 worker 共用**的工作区：backend / frontend / test 都在同一个 checkout 里
直接往 main 提交。本卡开工时 `git status` 里已经躺着别人的在途改动（`backend/src/business/erp/asset_*.rs`
/ `invoice.rs` / `opening.rs` / `report.rs` / 几份 20261107 的证据 raw 文件…）。

**没有用 `git add -A` / `git commit -a`**：那会把别人的半成品混进本卡的 commit。
只 `git add <本卡 13 个路径>`，`git diff --cached --stat` 复核过「暂存区只有本卡文件」再提交。
