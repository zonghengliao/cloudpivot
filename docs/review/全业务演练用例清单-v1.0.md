## 使用说明

### 用例格式

```
| 编号 | 用例名 | 前置 | 步骤 | 预期 |
```

### 编号规则

```
E2E-{域号}-{序号}
例：E2E-01-005 = 采购域第 5 个用例
```

### 级别标记

```
🔴 P0  阻断：走不通就没法用
🟠 P1  功能缺失：有页面但做不了
🟡 P2  逻辑错误：能走但结果错
🔵 P3  口径问题：结果对但理解容易错
⚪ P4  体验问题：能用但别扭
```

### 历史回归标记

```
🔄 标记的用例是「之前修过的 bug，验证没退化」
```

```

```

汇总 377 个用例的通过率 + 所有问题
