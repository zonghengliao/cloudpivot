## 四、缺失功能清单（按「客户会不会因此不买」排序）

### 4.1 会让客户直接否决的（🔴）

| # | 缺失 | 影响 | 现有基础 | 估算 |
|---|---|---|---|---|
| 1 | **生产制造（BOM/MRP/工单/工序/委外）** | 制造业客户第一句就问「有 BOM 吗」，没有=淘汰 | 库存/物料/成本都在，只缺生产环节 | 6-8 周 |
| 2 | **质量管理（IQC/IPQC/FQC/OQC）** | 制造业标配，贸易客户也问「收货检不检验」 | 入库/序列号/退货都在，检验单可挂入库前 | 3-4 周 |
| 3 | **资金管理（银行账户/对账/票据）** | 财务总监第一句「能对账吗」 | 应收应付/收付款/凭证都在 | 3-4 周 |
| 4 | **税务管理（增值税/发票认证/税表）** | 财务必问 | 有销售发票，无税务处理 | 3-4 周 |

### 4.2 已有模块内部的缺口（🟡 补齐即可，成本低）

#### 采购
- **采购计划**（年度/月度采购计划 → 订单）——有申请单，无计划层
- **框架协议 / 一揽子订单**——只有单次订单
- **供应商评估与准入**——有供应商档案，无评估打分/黑名单流程
- **采购合同关联**——有合同模块，但采购订单没挂合同号

#### 销售
- **报价单流转**——有「价格查询」，但**没有报价单 → 订单**的转换
- **客户信用实时控制**——有 `biz_credit_log`，但下单时**没有实时信用占用校验**
- **销售返利**——有佣金，无返利政策
- **销售预测**——有 `sales-target`（目标），无预测模型

#### 仓库
- **在途库存账**——有发货单，但**在途数量没有独立台账**（发货到签收之间账不清）
- **库龄分析 / 呆滞料报表**——完全没有
- **安全库存预警 / 补货建议**——没有
- **多组织/多仓调拨成本**——调拨有，但跨组织调拨的**内部结算价**没做

#### 财务
- **多币种核算**——有 `currency`/`exchange-rate`，但**账簿是单币种**，没有外币科目/汇兑损益
- **合并报表**——ARCH9 有设计，0 实现
- **现金流量表编制底稿**——有报表结果，无编制过程（直接法/间接法工作底稿）
- **往来账龄分析**——有 `payable-aging`，应收账龄缺

#### 成本
- **分批法（按订单/批次归集）**——ARCH9-3 设计有，刚完成的是**品种法基础版**
- **标准成本 + 差异分析**（价差/量差/效率差）——0 实现
- **在制品（WIP）约当产量法**——0 实现
- **成本还原**（半成品成本还原到料工费）——0 实现

#### 人力资源
- **招聘管理**（需求→简历→面试→offer）——0
- **培训管理**——0
- **绩效考核**——0
- **社保公积金规则**——有「薪资项」，但**没有社保基数/比例/封顶规则引擎**
- **排班管理**——考勤有，排班无
- **劳动合同管理**——0

#### 审批流
- **超时自动处理**（超时提醒有，自动通过/自动驳回没有）
- **加签 / 转签**——有委托，无运行中加签
- **条件分支可视化配置**——有表达式，但配置界面弱

#### 任务
- **资源负载视图**（谁手上多少活）
- **关键路径计算**（有依赖，无 CPM）
- **任务模板参数化**（有模板，实例化时不能带参）

## 六、一句话结论

**主链是通的、账是平的、测试是厚的——这三点在国内中小 ERP 里属于上游水平。**

**但它现在是一个「功能很全、结构偏乱、运维偏薄」的系统**：
- 功能全 = 采购销售库存财务的闭环真能跑通
- 结构乱 = 28 万行堆在 320 个文件里，模块互相咬着
- 运维薄 = 有备份没监控、有日志没告警、有测试没 CI 报告

**如果只做三件事**，我建议是：

```
① 清掉 41 条红测试（可信度问题，不做的话所有"全绿"都是假的）
② 接 /metrics + 告警（服务器挂了没人知道）
③ ERP 按域拆目录（纯移动，为后面所有改动降摩擦）
```

前两件是「补漏」，第三件是「还债」。
