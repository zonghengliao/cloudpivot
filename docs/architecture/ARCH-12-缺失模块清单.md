## 一、整块缺失的模块（12 个，0 实现）

### 1.1 制造业必备（4 个）🔴

#### 缺失 1：生产制造（MES）

| 项 | 内容 |
|---|---|
| **缺什么** | BOM（多级/版本/替代料）、MRP（物料需求计划）、生产订单、工单（派工/报工/进度）、工序（工艺路线/工序卡）、领料退料、完工入库、委外加工 |
| **为什么缺** | 用户 2026-11-09 明确「MES 暂停，等指令」 |
| **影响** | 制造业客户第一句就问「有 BOM 和工单吗」，没有 = 直接淘汰 |
| **现有基础** | 库存/物料/供应商/成本（移动加权）都在，但**没有生产环节** |
| **依赖** | 成本核算升级（ARCH9-3）必须先做，否则生产出来的东西算不出成本 |
| **预估工作量** | **约 6-8 周**（BOM/MRP/工单/工序/委外 五块，估 80-100 张卡） |

#### 缺失 2：质量管理

| 项 | 内容 |
|---|---|
| **缺什么** | IQC（来料检验）、IPQC（过程检验）、FQC（成品检验）、OQC（出货检验）、不合格品处理（让步接收/返工/报废）、退货检验、检验标准（AQL/抽样方案）、质量追溯、SPC 简单统计 |
| **为什么缺** | 从来没做过（`grep -r "qc\|inspect\|quality"` 在 erp 模块里 0 命中） |
| **影响** | 制造业标配；贸易客户也会问「收货要不要检验」 |
| **现有基础** | 有 `biz_stock_in`（入库）、`biz_material_serial`（序列号）、`biz_purchase_return`（退货）→ 检验单可以挂在入库前 |
| **依赖** | 无（可以独立做），但跟 MES 配套更完整 |
| **预估工作量** | **约 3-4 周**（估 35-45 张卡） |

#### 缺失 3：设备管理

| 项 | 内容 |
|---|---|
| **缺什么** | 设备台账（编号/型号/位置/责任人/技术参数）、保养计划（周期/项目/记录）、维修工单（报修/派工/完工/备件消耗）、备件库存、设备折旧（与固定资产联动）、设备状态（运行/停机/维修/报废）、点检记录 |
| **为什么缺** | 从没做过 |
| **影响** | 制造业/资产密集型企业需要；贸易客户不需要 |
| **现有基础** | 有 `biz_fixed_asset`（固定资产）→ 设备可以是固定资产的一种，但要独立的保养/维修子模块 |
| **依赖** | 无 |
| **预估工作量** | **约 2-3 周**（估 25-35 张卡） |

#### 缺失 4：成本核算升级（已有但很浅）

| 项 | 内容 |
|---|---|
| **缺什么** | 分批法（按订单/批次归集料工费）、标准成本（标准 vs 实际差异分析：价差/量差/效率差）、品种法（流程型生产）、制造费用分摊规则、在制品（WIP）约当产量法、成本结转凭证 |
| **为什么缺** | ARCH9-3 已设计（18 条定稿），但**一张卡都没实现** |
| **影响** | 现在只有移动加权平均 → **只能做贸易，做不了制造** |
| **现有基础** | 移动加权平均、库存三本账、凭证体系都在 |
| **依赖** | MES 提供料工费数据（或一期用人工录入） |
| **预估工作量** | ARCH9-3 已拆 **42 张卡**（约 6 周） |

### 1.2 通用业务缺（5 个）🟡

#### 缺失 5：客户关系管理（CRM）

| 项 | 内容 |
|---|---|
| **缺什么** | 线索（Leads）、商机（Opportunity）、跟进记录（拜访/电话/邮件）、销售漏斗（阶段推进）、客户分级、客户拜访计划、报价单审批流（有 `biz_price_quote` 但没 CRM 流程）、客户流失预警 |
| **为什么缺** | 有 `biz_customer`（档案）+ `biz_customer_contact`（联系人）+ `biz_credit_log`（信用），但**没有 CRM 的前段流程** |
| **影响** | 销售驱动型客户会问「能管商机吗」；制造业客户不太在意 |
| **现有基础** | 客户档案、价格体系、销售目标、佣金规则都有 → CRM 是「往前接一段」 |
| **依赖** | 无 |
| **预估工作量** | **约 3-4 周**（估 40-50 张卡） |

#### 缺失 6：售后服务

| 项 | 内容 |
|---|---|
| **缺什么** | 服务工单（报修/派工/上门/完工/回访）、安装管理、维修管理（维修记录/备件消耗/收费）、退换货处理流程（有 `biz_sales_return` 但没服务流程）、服务合同（年度维保）、客户满意度回访 |
| **为什么缺** | 从没做过 |
| **影响** | 设备类/工业品类客户需要；快消不需要 |
| **现有基础** | 有销售退货、库存、工单类（`biz_task` 可以复用一部分模式） |
| **依赖** | 无（可以独立），跟设备管理配套更好 |
| **预估工作量** | **约 2-3 周**（估 30-40 张卡） |

#### 缺失 7：资金管理

| 项 | 内容 |
|---|---|
| **缺什么** | 银行账户管理、现金日记账、银行日记账、**银行对账**（导入流水 → 自动匹配）、票据管理（银行承兑/商业承兑/背书/贴现/到期）、资金计划（月度/周度现金流预测）、融资管理、内部资金调拨 |
| **为什么缺** | 有 `biz_receipt`/`biz_payment`（收付款），但**没有账户/对账/票据** |
| **影响** | 财务总监会问「能对账吗」；这是财务闭环的关键一环 |
| **现有基础** | 应收应付、收付款、凭证都在 → 资金管理是「往下接一段」 |
| **依赖** | 无 |
| **预估工作量** | **约 3-4 周**（估 40-50 张卡） |

#### 缺失 8：税务管理

| 项 | 内容 |
|---|---|
| **缺什么** | 增值税申报表（自动取数：销项-进项）、发票认证（进项勾选）、进销项匹配、税负分析、附加税/所得税计算、税务档案 |
| **为什么缺** | 有 `biz_invoice`（发票表），但没有**金税对接 + 验真 + 申报** |
| **影响** | 中型以上客户会问「能出申报表吗」；小微客户用记账公司 |
| **现有基础** | 有发票表（含 `is_electronic`）、税额字段、凭证体系 |
| **依赖** | 需要对接金税/税局 API（外部依赖） |
| **预估工作量** | **约 2-3 周**（不含外部对接，估 25-35 张卡） |

#### 缺失 9：供应链协同（SRM）

| 项 | 内容 |
|---|---|
| **缺什么** | 供应商门户（供应商自己登录看订单/送货/对账）、招投标、送货协同（ASN 预发货通知）、对账协同（月结对账单在线确认）、供应商绩效评估（交期/质量/价格） |
| **为什么缺** | 有 `biz_supplier`（档案）+ `biz_price_inquiry`（询比价），但**没有供应商协同门户** |
| **影响** | 大客户会问「供应商能自己登录吗」；中小客户不需要 |
| **现有基础** | 采购订单、收货、应付、对账（`biz_statement_confirm`）都有 |
| **依赖** | 需要多用户体系（已有）+ 外部访问（要考虑安全） |
| **预估工作量** | **约 3-4 周**（估 35-45 张卡） |

### 1.3 特定行业（3 个）🟢

#### 缺失 10：零售/门店

#### 缺失 11：项目管理深度（有但很浅）

| 项 | 内容 |
|---|---|
| **现在有什么** | `biz_project`（项目）、`biz_project_member`（成员）、`biz_task_worklog`（工时） |
| **缺什么** | 项目预算（按项目编预算）、项目进度（WBS/里程碑/甘特——有任务甘特但没项目级）、项目成本归集（料工费按项目汇总）、项目收入确认（完工百分比法）、项目毛利分析、项目结项 |
| **为什么缺** | 有项目表但只是「任务的容器」，没有项目财务 |
| **影响** | 工程/咨询/软件类客户需要 |
| **现有基础** | 项目表 + 任务 + 工时 + 预算模块（可以映射） |
| **依赖** | 无（但跟成本核算升级配套更好） |
| **预估工作量** | **约 2-3 周**（估 30-40 张卡） |

#### 缺失 12：委外加工

| 项 | 内容 |
|---|---|
| **缺什么** | 委外订单（委外生产什么）、委外发料（把原料发给供应商）、委外收货（收成品）、委外加工费结算、委外损耗管理、委外进度跟踪 |
| **为什么缺** | 属 MES 范畴，MES 暂停了 |
| **影响** | 制造业客户（自己产能不足要委外）需要 |
| **现有基础** | 采购订单/收货/应付 + 库存调拨（可以复用部分） |
| **依赖** | MES（或独立做简化版） |
| **预估工作量** | **约 2 周**（估 25-30 张卡） |

```

  ≈ 14-18 周（并发 2 → 7-9 周）

工程/咨询包：项目管理深度 + 人力 + 资金
  ≈ 11-14 周（并发 2 → 6-7 周）
```
