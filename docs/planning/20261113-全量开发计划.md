## 九、估算的诚实说明

**这 73.2 人日是怎么算的**：

```
单卡 ≤1.5h    →  345 卡 × 1.5h = 517.5h = 64.7 人日
加回归/上线   →  +8.5 人日（P1/P2/O 各留缓冲）
              →  73.2 人日
```

**实际会超的原因**（本项目的真实教训）：

| 教训 | 影响 |
|---|---|
| worker 崩溃（EOFError） | 今天一上午崩了 4 次，每次重跑损失 20-25 分钟 |
| 门禁挡住 push（别人 WIP 弄红 rustfmt） | 今天两次，每次多等 4-5 分钟 |
| 卡"看起来在跑"实际空转 | HR-41/HR-34 各空转 5.5 小时 |
| 夹具顺序依赖 | 41 条红，每条都要查是"真错"还是"环境脏" |

**所以真实吞吐按 8 卡/天算**（理论 10-12 卡/天打 7 折），345 卡 ≈ 43 个工作日 ≈ 8.6 周。

**如果 P2.7 不做**（20 卡），降到 325 卡 ≈ 41 个工作日 ≈ 8.2 周。

**如果 HR 只做 2 项**（省 34 卡），降到 311 卡 ≈ 39 个工作日 ≈ 7.8 周。
