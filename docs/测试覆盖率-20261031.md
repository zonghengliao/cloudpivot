**⑦ 为什么 12:03 轮没重跑 E2E**：同一时刻「测试E · 52 页全量」那张卡正在打**同一台生产**跑 9 个 spec，
生产全局限流 300 req / 60s 按**客户端 IP** 计，两轮叠一起必然 429（本仓 README 有复现记录）。
宁可只报 11:56 那一轮的真数，也不制造一次假红。合并跑法：等那边跑完 ≥65s 再 `--only e2e`。

**读法**：①③ 真绿；② 是别人在途测试红（不是本卡引入）；④⑤⑥ 是环境未就绪（**SKIP 不等于通过**，
只是不冒充失败）；⑦ 4 条 spec 真红要修；⑧ 是在途改动没 fmt。
改这份文档之前，8 个 stage 里只有 **2 个能真跑绿**——这就是为什么必须先有系统性用例，而不是继续加零散断言。
